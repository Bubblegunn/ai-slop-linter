# Roadmap

Three next steps, in no particular order. Open an issue if you want to take one.

- A `--baseline` mode that records today's findings and only fails on new ones, so a large repository can adopt the linter without a cleanup commit first
- A VS Code problem matcher (and then an extension) so findings show inline while writing
- Rule sets for a second language; the constructions carry over, the vocabulary does not

Things deliberately not planned: a probability that a text was machine-written. The tool lists tells; it does not judge authorship.
