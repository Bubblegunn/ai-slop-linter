# Brightlog Anleitung

Brightlog 3.2.0 sendet Protokolle an `https://logs.brightlog.example/v3/ingest`. Es ist wichtig zu beachten, dass Python 3.9 oder neuer nötig ist. Die Software ist nahtlos und ein Zeugnis moderner Technik. Ich hoffe, das hilft.

## Fehlermeldung

Bei einem abgelaufenen Token nach 24 Stunden zeigt das Programm „Ungültiger API-Schlüssel“ an.

## Hinweise

Das Werkzeug – so steht es im Handbuch – ist schnell. Details stehen auf den Seiten 10–12. Die Standardgröße beträgt 500 Ereignisse.
