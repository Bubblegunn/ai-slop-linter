# Guide Brightlog

Brightlog 3.2.0 envoie vos journaux vers `https://logs.brightlog.example/v3/ingest` en moins de 200 ms.

## Installation

Lancez `pip install brightlog==3.2.0`. Python 3.9 ou plus récent est requis. Le guide est court parce que l'outil est simple.

## Dialogue d'exemple

Voici un échange typique dans le terminal d'aide :

- Quelle version utilises-tu ?
- La 3.2.0, répond Camille.
- Alors tout va bien !

Quand le jeton expire après 24 heures, le message "Clé d'API invalide" s'affiche.
